## Short description (max 132 characters)

```
Generate readable usernames in one click. Presets, history, favorites, 8 languages, dark mode. Works fully offline.
```

## Category

Productivity

## Language

English

## Single purpose statement

```
Generate random usernames and copy them to the clipboard.
```

## Permission justification

```
storage — Saves username history, favorites, and display preferences locally, and keeps
favorites and preferences in sync across the user's own devices. No other permissions are
requested.
```

## Remote code

```
No. The extension does not use remote code, external scripts, or eval of any kind.
```

## Data usage disclosures

```
The extension does not collect or transmit user data. History, favorites, and preferences are
stored in chrome.storage and never leave the browser. No analytics, no tracking, no ads.
```

## Detailed description

```
Stop staring at the "choose a username" field.

Username Generator creates usernames that are actually easy to say, easy to read, and easy to
remember — in one click, without an account and without a single network request.

★ FOUR WAYS TO GENERATE

• Quick presets — Gaming ID, Social handle, Readable word, and Strong, each with sensible
  defaults for length and character set.
• Easy to say — alternating consonant and vowel syllables, so the name rolls off the tongue.
• Easy to read — removes ambiguous characters (I, l, 1, O, 0, S, 5, B, 8, Z, 2) so nobody
  misreads it.
• All characters — full control over uppercase, lowercase, numbers, and symbols.

★ BUILT FOR SPEED

• Toolbar popup with one-click generate and copy
• Auto-copy option: generate and the name is already on your clipboard
• Batch generation: get 10 options at once and click the one you like
• Keyboard shortcuts: Enter to generate, Ctrl/Cmd+C to copy
• Length from 3 to 30 characters, with synced slider and input

★ KEEPS YOUR GOOD ONES

• History of your last 50 usernames with timestamps
• Star favorites so you never lose the winner
• Search your history instantly
• Export to CSV or JSON, import JSON to move devices

★ MADE TO FIT YOU

• 8 interface languages: English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch
• Light, dark, or follow the system theme
• Full-page workspace for history and favorites, compact popup for quick jobs
• Keyboard accessible, screen-reader friendly, works on narrow screens

★ PRIVATE BY DESIGN

• No account, no sign-up, no ads, no analytics
• Zero network requests — it works completely offline
• Only permission requested is "storage"
• History never leaves your device; favorites and preferences sync only through your own
  Chrome profile, if you enable sync

Open source: https://github.com/1ifebytes/username-generator

Whether you are naming a game character, claiming a social handle, or generating test accounts,
you get a usable name in under two seconds.
```
