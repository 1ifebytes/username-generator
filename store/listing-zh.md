# Chrome 应用商店文案 — 简体中文

以下内容可直接粘贴到应用商店提交表单。注意：一个扩展只能提交一种商店语言；如需中文商店页，
请把下表内容填写在本地化（Localization）信息里。

---

## 名称（≤45 字符）

```
用户名生成器 — 快速易读
```

## 简短说明（≤132 字符）

```
一键生成易读用户名。场景预设、历史记录、收藏、8 种语言、深色模式，完全离线运行。
```

## 类别

生产力工具（Productivity）

## 单一用途说明

```
生成随机用户名并复制到剪贴板。
```

## 权限说明

```
storage —— 用于在本地保存用户名历史、收藏与显示偏好，并在用户自己的多台设备间同步收藏与
偏好。不申请其他任何权限。
```

## 远程代码

```
无。扩展不使用远程代码、外部脚本或任何形式的 eval。
```

## 数据使用声明

```
本扩展不收集、不传输任何用户数据。历史、收藏与偏好保存在 chrome.storage 中，不会离开浏览器。
无分析、无追踪、无广告。
```

## 详细说明

```
不用再对着「请输入用户名」发呆。

用户名生成器一键生成真正好读、好念、好记的用户名 —— 无需注册，不发起任何网络请求。

★ 四种生成方式

• 快速预设 —— 游戏 ID、社交账号、易读单词、高强度，每种都配好了合适的长度与字符组合。
• 易于发音 —— 辅音与元音交替，念起来顺口。
• 易于阅读 —— 剔除易混淆字符（I、l、1、O、0、S、5、B、8、Z、2），不会被看错。
• 全部字符 —— 大写、小写、数字、符号完全自定义。

★ 为速度而做

• 工具栏弹窗，一键生成与复制
• 自动复制：生成后用户名已在剪贴板
• 批量生成：一次给 10 个候选，点哪个复制哪个
• 快捷键：Enter 生成，Ctrl/Cmd+C 复制
• 长度 3–30，滑杆与输入框同步

★ 留住好的名字

• 最近 50 条历史记录，带时间戳
• 星标收藏，好名字不会丢
• 历史即时搜索
• 导出 CSV 或 JSON，导入 JSON 即可换设备

★ 贴合你的习惯

• 8 种界面语言：English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch
• 浅色、深色，或跟随系统
• 全页面用于管理历史与收藏，轻量弹窗用于快速生成
• 支持键盘操作与屏幕阅读器，窄屏也能用

★ 隐私优先

• 无账号、无注册、无广告、无分析
• 零网络请求，完全离线可用
• 仅申请「storage」一项权限
• 历史只存本机；收藏与偏好仅通过你自己的 Chrome 账号同步

开源地址：https://github.com/1ifebytes/username-generator

无论是给游戏角色取名、抢注社交账号，还是批量生成测试账号，都能在两秒内拿到可用的名字。
```
