# Username Generator (Chrome Extension)

English:
- Full-page username generator for Chrome (Manifest V3).
- Modes: Easy to say (pronounceable consonant/vowel pattern), Easy to read (ambiguous chars removed), All characters.
- Toggles: uppercase, lowercase, numbers, symbols; length input + slider stay in sync.
- History: saves up to 50 records in `chrome.storage.local`, shows timestamps (YYYY-MM-DD HH:mm:ss local), lazy loads, click to copy, delete single, clear all.
- Action opens a new tab (`chrome-extension/page.html`); clipboard feedback with alerts.

中文：
- 面向 Chrome 的全页面用户名生成器（MV3）。
- 模式：易于发音（辅音/元音交替）、易于阅读（移除易混淆字符）、全部字符。
- 选项：大小写、数字、符号可选；长度输入与滑条同步。
- 历史：使用 `chrome.storage.local` 保存最多 50 条，显示本地时间戳（YYYY-MM-DD HH:mm:ss），懒加载，点击复制，支持单条删除与清空。
- 扩展文件位于 `chrome-extension/` 目录；点击扩展图标打开新标签页（`chrome-extension/page.html`），复制操作有提醒。

中文（香港廣東話）：
- Chrome 全頁版用戶名產生器（MV3）。
- 模式：易講（子音/母音交替）、易讀（去除易混字符）、全部字符。
- 選項：大細階、數字、符號自由揀；長度輸入同滑桿同步。
- 歷史：`chrome.storage.local` 儲存最多 50 條，顯示本地時間（YYYY-MM-DD HH:mm:ss），支援懶加載，點擊可複製，亦可刪單條或清空。
- 擴充檔案放在 `chrome-extension/` 內；點擊擴充圖示會開新分頁（`chrome-extension/page.html`），複製會有提示。
