# 变更：记录并展示用户名生成历史

## Why
需要把用户生成过的用户名存储下来，并按时间（精确到秒）倒序展示，方便查看和复制历史结果。

## What Changes
- 在生成用户名时写入浏览器存储，包含用户名与时间戳（精确到年月日时分秒）。
- 使用 `chrome.storage.local` 保存最近 50 条唯一记录，生成（包括初始自动生成）时写入；遇到重复则更新时间并置顶。
- 在全页面视图中展示历史列表，按时间倒序排列并显示 YYYY-MM-DD HH:mm:ss（本地时区），支持懒加载。
- 支持点击历史项复制、单条删除与清空全部；列表位于生成器下方，限定高度可滚动。
- 确保列表随新生成项即时更新，保留现有生成与复制功能。

## Impact
- 影响的规格：username-generator
- 影响的代码：page.html / popup.js、样式、测试、可能的存储辅助代码
